# Non-Functional Requirements Results:
[NFR-001]: Windows NT execution environment  
**Description:** The Center-to-Center Server shall execute in a Microsoft Windows NT environment. The Center-to-Center shall execute in a Microsoft Windows NT environment.  
**Quality Attributes**: Portability, Compatibility, Security  
**Measurable Criteria (if provided):** Acceptance: Deployment image must show all critical security patches for Windows NT 4.0 SP6a; system shall disable all unnecessary services, run under restricted local account, OPSEC hardening checklist passed, deployment SHALL occur in isolated subnet with all non-required ports/services disabled, and documented third-party security risk review.  
**Dependencies** / **Conflicts**:  
- **Depends on:** ASR-004
