## Language

en_us

## Programming Language

ActionScript (Flash) / JavaScript / HTML

## Original Requirements

Develop 'Space Fractions', a web-based interactive learning tool for 6th-grade students to improve fraction-solving skills. The system includes an introductory movie, main menu, storyline-driven multiple-choice fraction questions, scoring mechanism, and an ending scene. It requires a Flash-supporting browser. An admin tool (Question Updater) allows teachers to modify questions. A 'Math Umbrella' menu links to related educational projects. The system must accommodate different user personas (story-focused, competitive, teacher) and run on standard internet-accessible computers without new hardware.

## Project Name

space_fractions

## Product Goals

- Improve 6th-grade students' fraction arithmetic and conceptual understanding through gamification
- Provide an adaptive learning experience that engages both story-oriented and competitive students
- Empower teachers to customize content and track student progress via an admin interface

## User Stories

- As Alice (student), I want a compelling storyline so that I stay engaged even though I find computers boring
- As Bobby (student), I want to see my score and rank at the end so I can compete with myself or others
- As Claire (teacher), I want to update fraction questions via a web form so I can tailor the difficulty to my class
- As a student, I want a robotic sidekick to give hints so I don't get frustrated when stuck
- As a returning user, I want to skip the introductory movie so I can start playing immediately

## Competitive Analysis

- Khan Academy: High curriculum alignment, but lower gamification and storyline engagement
- Prodigy Math Game: High engagement and RPG elements, but subscription-based and less teacher-customizable
- Math Blaster: Strong gamification, but often lacks specific curriculum customization for teachers
- IXL Math: Comprehensive tracking and curriculum, but low gamification and less engaging for reluctant learners
- Coolmath Games: High engagement, but variable educational quality and lack of teacher oversight
- DragonBox Numbers: Excellent conceptual learning, but limited scope compared to a full fraction system
- Our Target Product: Balances storyline (for Alice) and competition (for Bobby) with teacher customization (for Claire)

## Requirement Analysis

The SRS defines a client-server web application. Client-side requires Flash for interactive movies and gameplay (intro, menu, questions, ending). Server-side requires a web server to host the system and an admin interface for the Question Updater. Key functional requirements include input validation (fractions), score calculation, storyline branching based on critical questions, and external linking (Math Umbrella). Non-functional requirements include browser compatibility (Flash), download speed optimization for modems, and security via browser standards. A significant conflict exists between 'multiple-choice' interaction and 'fraction input for velocity' described in different sections.

## UI Design draft

Flash-based cartoon interface with a space theme. Main Menu includes 'Start', 'Help', and 'Links' buttons. Gameplay screen features a robotic sidekick avatar, question text, multiple-choice buttons, and score display. Admin interface uses standard web forms with dropdowns and text fields for question editing. Colors should be vibrant to engage 6th graders, with clear typography for readability.

## Anything UNCLEAR

1. The SRS mentions Flash movies, but Flash is deprecated and no longer supported by modern browsers; this requires a technology stack migration plan (e.g., to HTML5/JavaScript). 2. There is a contradiction in input methods: one section states 'multiple-choice questionnaire', while another states 'inputs will consist of fractions entered by the player... two integers'. Clarification is needed on whether students select options or type fractions. 3. The 'velocity adjustment' mechanic is mentioned but not fully integrated into the multiple-choice flow description.
