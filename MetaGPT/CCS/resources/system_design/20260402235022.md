## Implementation approach

We will use Python for the high-level control logic and API due to its maintainability and rich ecosystem, with C++ bindings for low-level hardware drivers where real-time performance is critical. The architecture employs a Master/Slave pattern using ZeroMQ for robust, asynchronous communication between nodes. FastAPI will power the Virtual Correlator Interface (VCI) providing REST and WebSocket endpoints for real-time monitoring. SQLAlchemy will handle persistent configuration and audit logging. A dedicated Watchdog service will monitor heartbeats and manage autonomous recovery. Security will be enforced via JWT authentication and role-based access control (RBAC).

    Sec-->>VCI: allowed

    HW-->>Slave: success

    Master-->>VCI: result
    VCI-->>User: response

    Slave->>Master: re_register()
