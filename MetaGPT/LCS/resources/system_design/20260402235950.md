## Implementation approach

We will adopt a Modular Monolith architecture using Python to ensure simplicity and maintainability while meeting safety-critical requirements. The system will use `asyncio` for concurrent handling of GUI events, hardware polling (2s interval), and logging without blocking the main thread. `PyQt6` will be used for the desktop GUI to ensure robust 24/7 operation. Safety interlocks will be implemented as a mandatory middleware layer in the control logic, independent of the UI. `SQLAlchemy` with SQLite (WAL mode) will manage local configuration and immutable audit logs. `bcrypt` will be used for password hashing (upgrading from the required MD5 for security). Hardware communication will be abstracted via a Driver Pattern to accommodate unspecified controller models.

    end
    
    O->>GUI: click_open_lane(lane_id)
    GUI->>SEC: check_permission(role, OPEN)
    SEC-->>GUI: return allowed
    GUI->>CORE: execute_command(Command)
    CORE->>LOCK: validate_command(Command, current_state)
    alt Safety Check Failed
        LOCK-->>CORE: return False (Conflict)
        CORE->>DB: log_audit(FAILED, user, reason)
        CORE-->>GUI: return Error
    else Safety Check Passed
        LOCK-->>CORE: return True
        CORE->>HW: send_command(lane_id, OPEN)
        HW-->>CORE: return Success
        CORE->>DB: log_audit(SUCCESS, user, command)
        CORE-->>GUI: return Success
    end
    GUI->>O: display_result()


## Anything UNCLEAR

1. Hardware Protocol: The specific communication protocol (Modbus, TCP/IP, Serial) for the FCU/DCU controllers is not finalized, requiring a flexible driver abstraction. 2. Security Standard: The requirement specifies MD5 for password hashing, which is cryptographically broken; the design uses bcrypt but needs stakeholder approval for this security upgrade. 3. Legacy OS: Requirements mention Windows NT/HP UX, which are end-of-life and insecure; the design targets modern Windows 10/11 or Linux LTS for security compliance. 4. Network Topology: Bandwidth constraints for future DCU expansion are undefined, potentially affecting polling frequency.
